# Quantum Mechanics

Numerical solutions of the time-independent Schrodinger equation.

| Script | Description |
|---|---|
| `hydrogen-matrix-method.py` | Radial Schrodinger equation for hydrogen solved by matrix diagonalization on a discretized grid |
| `hydrogen-radial-wavefunctions.py` | Analytic radial wavefunctions from associated Laguerre polynomials, normalized by numerical integration |
| `finite-potential-well-schrodinger.py` | Bound states of a finite square well via shooting method |
| `quantum-double-well-wavefunction.py` | Tunneling and eigenstates of a double-well potential |
| `harmonic-oscillator-numerical.py` | Quantum harmonic oscillator eigenstates by numerical integration |
